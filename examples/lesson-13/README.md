# 第 13 课：静态成员与友元函数

这里保留 Project13 的两类练习，每份源码都是独立程序。

| 版本 | 源码 | 练习内容 | 运行输出 |
|---|---|---|---|
| 静态成员 | [main.cpp](main.cpp) | `static` 数据成员、类外定义、通过构造函数累计创建的对象数 | 依次输出 `1`、`2` |
| 友元函数与对象生命周期 | [friend-function/main.cpp](friend-function/main.cpp) | 友元函数读取私有成员；用 `inline static` 累计创建数量；观察局部对象的析构顺序 | 依次输出 `2`、`7`、`2` |

静态成员版本沿用仓库已有代码。友元函数版本归档自本机 Project13 的 `13.cpp`，于 2026-11-01 同步最新代码，代码逻辑保持原样。这是两类练习的归档，不代表已恢复所有历史编辑记录。

当前的 `created` 记录累计创建的对象数，析构时没有递减，所以对象 `b` 和 `a` 析构时都输出 `2`。中间的 `7` 是友元函数读取的私有成员值。早先只输出 `7` 的友元函数版本可在提交历史中查看。

在 Visual Studio 控制台项目中运行时，每次只添加其中一个源码文件，避免两个 `main` 函数同时参与编译。
