# 练习修正记录

本次修改基于仓库的 `178bda3` 提交。第 1 课头文件末尾的多余分号已在该提交修正，本次保留。桌面上的原始上机目录没有修改。

## 第 1 课：输出拼写

将 `Goal:lean c plus plus.` 改为 `Goal:learn c plus plus.`。程序其余输出不变。

## 第 7 课：计数上限

练习要求最多统计 1000 个正数，原程序一直统计到遇到 0 或读取结束。输入 1001 个正数时，原程序输出 1001。

现在每统计一个正数就检查上限，达到 1000 时结束。负数仍被跳过，0 仍作为结束标记，非数字或输入结束仍停止读取。

回归检查覆盖 999、1000、1001 个正数，以及正负数交替输入，确认负数不占计数名额。

## 第 9 课：读取失败

原程序没有检查读取结果。输入 `abc 8` 会输出两个 0；输入 `3 abc` 会输出 `a:0` 和 `b:3`，这些输出没有表示用户成功输入的两个数。

现在两个整数都成功读取后才交换；非数字、整数超出范围、只输入一个整数后结束或没有输入时，输出 `invalid`，并以退出码 1 结束。正常整数输入的行为保持不变。

## 第 11、12 课：计数器边界

`setvalue()` 原本拒绝负数，但带参数构造函数直接赋值，允许对象以负数开始。本次让构造函数使用同一套设置规则：负数参数不会覆盖默认值 0。

原来的 `crease()` 对整数最大值加一，可能发生有符号整数溢出。现在先检查上限，到达最大值时返回 `false`，值保持不变；正常加一返回 `true`。函数名保留原练习中的 `crease`。

这两课的演示 `main()` 输出保持不变。额外测试复用实际类代码，检查默认构造、合法和非法构造、合法设置、拒绝负数时保留旧值，以及加一的上下边界。
